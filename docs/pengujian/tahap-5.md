Akun: `staff.qc`, `leader.qc` / `demo12345`

## A. QC per unit
- [ ] A1. Scan SN di Lini QC → checklist sesuai jenis produk (versi terbaru) tampil.
- [ ] A2. Tombol **Lulus/Gagal** per poin; **Tandai semua lulus** mempercepat.
- [ ] A3. Poin wajib belum diisi → ditolak dengan nama poinnya.
- [ ] A4. Semua lulus → **Simpan: LULUS QC** → unit pindah ke Packing.
- [ ] A5. Ada poin gagal → tombol berubah merah; catatan **wajib**; pilih tujuan rework (Assembling/Aktivasi) → unit kembali ke tahap itu, riwayat unit mencatat "Dikembalikan (rework)" beserta catatan.
- [ ] A6. Gagal dengan tujuan "Tetap di QC" → unit tetap di antrian QC untuk diperiksa ulang.
- [ ] A7. **Foto QC**: tombol *Ambil / Upload Foto* (di HP langsung membuka kamera) → foto tampil kecil; klik untuk ukuran penuh. Foto memiliki watermark tanggal/jam, SN, dan nama petugas di bagian bawah.
- [ ] A8. Riwayat QC tampil di bawah form dan di halaman detail unit (hasil per poin + catatan).

## B. QC sampling per lot
Buat project baru dengan **Mode QC: Sampling** (misalnya lot 10, sampel 20%, batas gagal 0), bawa unit sampai QC.
- [ ] B1. Pilih project di filter antrian Lini QC → panel **Lot QC** tampil.
- [ ] B2. Scan unit sebelum lot dibentuk → pesan "bentuk lot dulu".
- [ ] B3. **Bentuk Lot Baru** → LOT-001 berisi N unit, sampel dipilih acak (SN sampel tampil).
- [ ] B4. Scan unit non-sampel → pesan "bukan sampel".
- [ ] B5. Semua sampel lulus → lot **Lulus**, seluruh unit lot pindah ke Packing.
- [ ] B6. Sampel gagal melebihi batas → lot **Ditahan**; staff hanya melihat "Menunggu keputusan".
- [ ] B7. `leader.qc`/Manager: **Loloskan lot** (alasan wajib) atau **Kembalikan seluruh lot** ke Assembling/Aktivasi.

- [ ] C2. Foto hanya bisa dihapus oleh pengunggah atau Manager/Super Admin.
