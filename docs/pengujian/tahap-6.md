- [ ] 2. **Koli Baru** → kode otomatis `<kode project>-K0001`, berikutnya `-K0002`.
- [ ] 3. Scan beberapa SN sekaligus (dipisah spasi/Enter) → unit masuk koli.
- [ ] 4. Unit yang kelengkapannya belum lengkap → ditolak dengan pesan "Kelengkapan belum lengkap: …".

- [ ] 6. Keluarkan unit dari koli terbuka (ikon tempat sampah).
- [ ] 7. **Foto packing** bisa diunggah.
- [ ] 8. Isi berat (opsional) → **Segel Koli** → unit pindah ke antrian Ekspedisi; koli tersegel tidak bisa ditambah unit.
- [ ] 9. **Buka segel** (sebelum masuk pengiriman) → unit kembali ke Packing.
- [ ] 10. Koli kosong tidak bisa disegel; bisa dihapus.
- [ ] 11. **Label & Packing List** → halaman cetak: label besar dengan barcode kode koli + tabel SN & kelengkapan. Tombol **Cetak** mencetak tanpa tombol-tombolnya.
