## A. Pengiriman
- [ ] A1. Lini Ekspedisi → pilih project → **Pengiriman Baru** → nomor surat jalan otomatis `SJ-<kode project>-001`.
- [ ] A2. Scan kode koli (atau banyak sekaligus) → koli masuk. Koli belum disegel / project lain / sudah di pengiriman lain → dilaporkan.
- [ ] A3. Keluarkan koli selama status Disiapkan.
- [ ] A4. **Kirim** tanpa ekspedisi → tombol tidak aktif. Pilih ekspedisi, isi resi & kendaraan → status **Dalam perjalanan**.
- [ ] A5. **Surat Jalan** → halaman cetak berisi tujuan & alamat, PO, ekspedisi & resi, daftar koli, total unit/berat, kolom tanda tangan.
- [ ] A6. Isi nama penerima → **Konfirmasi Diterima** → status Diterima; unit pindah ke Instalasi (kalau tahap instalasi dipakai) atau **Selesai**.
- [ ] A7. **Foto pengiriman & BAST** bisa diunggah (foto atau PDF).
- [ ] A8. Satu project bisa punya beberapa pengiriman (pengiriman parsial).

## B. Instalasi (untuk item yang memakai tahap Instalasi, misalnya IFP/Server)
- [ ] B1. Lini Instalasi → isi lokasi → scan SN unit (beberapa sekaligus) → **Selesai Instalasi** → unit Selesai.
- [ ] B2. Detail unit → bagian Informasi Unit menampilkan lokasi instalasi; **Foto instalasi** bisa diunggah.

## C. Penyelesaian project
- [ ] C1. Setelah **semua** unit pesanan selesai, status project otomatis menjadi **Selesai**.
